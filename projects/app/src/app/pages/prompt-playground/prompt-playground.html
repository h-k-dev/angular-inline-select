angular-inline-prompt edits Markdown's line shapes — # headings, - bullets, 1. numbered items, one level of nesting with Tab — as shapes, and stores the Markdown a language model reads. Numbers are counted: add an item in the middle of a list and the rest renumber. A stored prompt always reads back byte for byte.
