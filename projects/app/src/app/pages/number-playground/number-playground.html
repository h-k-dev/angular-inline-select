Inline number

angular-inline-number composes the text control — no inheritance — and translates numbers at the contract boundary through a swappable parse/format codec.

The vessel carries crew members. The binding accepts a string or a number on the way in; every keystroke parses live and every commit is a number — model: {{ crewCount() ?? '∅' }} ({{ crewCountType() }}).

Price + suffix

Unit price: euro per crate. The codec formats two decimals, the editableSuffix template renders with the field in both states — idle in the copy and inside the elevated editor — and is never part of the draft. The unit lives in ariaLabel; the icon is decorative — model: {{ price() ?? '∅' }}.

Restricted input (opt-in filter)

Fuel reserve:  L aboard. Type 12ab,5: the letters never land in the draft, and the comma reads as a decimal point, so the model is {{ fuelReserve() ?? '∅' }} ({{ fuelReserveType() }}) — the bound field only ever sees a dot-decimal number. This field runs decimalSeparator="both", so the idle text settles on the canonical dot.

Press a letter on the resting field and nothing happens at all — no editor, no announcement, because only a real mutation elevates and rejection is silent. Same for pasting N/A onto an empty field, so name the constraint in ariaLabel rather than leaving users to discover it. The filter is not a validator: 1.2.3 survives it and the parse gate still blocks the save.

Comma decimals

Cable length:  m of cable. Here decimalSeparator="," governs both halves of the codec, so the idle text reads 48,5 — while the model stays a dot-decimal {{ cableLength() ?? '∅' }} ({{ cableLengthType() }}). A separator never crosses the contract boundary.

Type 1.5 here: the filter admits the dot — it admits digits, sign and BOTH separators whatever the codec is, so no keyboard ends up with a dead decimal key — and the codec then rejects it visibly through the parse gate ({{ cable.parseFailed() ? 'currently failing' : 'currently parsing' }}). A silently swallowed key would be the worse failure.
